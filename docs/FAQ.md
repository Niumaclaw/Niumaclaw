# NiumaClaw 常见问题

## 下载点击后没反应

- 确认浏览器允许 `niuma.wiki` 下载文件。
- 重新打开“下载客户端”弹窗，再点击对应平台按钮。
- 如果网络很慢，等待浏览器下载栏出现文件名。
- 仍失败时，刷新页面后重试。

## macOS 提示无法验证或文件损坏

当前 MVP 包可能还没有完成 Developer ID 签名和 notarization。可以先右键 `NiumaClaw Agent.app`，选择“打开”。正式商业发布前应完成签名公证，避免默认拦截。

## 桌面端显示已连接，但网页端没有在线客户端

- 保持桌面端窗口打开。
- 回到网页端点击“查看在线客户端”。
- 确认登录的是同一个账号。
- 如果刚重置过 token，请重新下载客户端或更新手动 Runner token。

## 派工后桌面端不干活

- 打开员工工作日志，展开智能体面板查看最近运行。
- 如果提示 `codex: command not found`，先按 [Codex CLI 安装与登录说明](CODEX_CLI_SETUP.md) 修复命令。
- 如果提示 token 失效，重新下载客户端并绑定员工。
- 如果任务一直排队，检查客户端是否在线、工作区是否可写。

## 工作日志没有最终回复

- 刷新网页端工作日志。
- 确认桌面端日志里任务已经完成。
- 查看“最近运行”是否显示失败原因。
- 如果失败原因是 timeout、permission denied 或 command not found，按提示修复后重新派发任务。

## 什么时候需要解绑节点

出现以下情况时建议解绑：

- 换电脑或重装客户端。
- 怀疑客户端 token 泄露。
- 员工不再使用当前本机 Agent。
- 节点一直离线，但网页端仍显示旧节点。

解绑后旧 token 会立即失效，该客户端不能继续领任务。

## 重置 token 和解绑有什么区别

- 重置 token：保留节点记录，但旧 token 失效。适合手动 Runner 或需要换密钥的场景。
- 解绑节点：撤销节点 token，并解除员工绑定。适合换机、删除节点或停止使用。

## 下载速度慢

客户端包包含原生桌面端运行文件，Windows 和 macOS 包几十 MB 属于正常范围。若下载极慢：

- 避开网络高峰时段。
- 换一个浏览器重试。
- 保持页面打开，等待浏览器完成下载。

后续商业版本应把静态下载文件放到 CDN 或对象存储。
