# NiumaClaw 5 分钟快速开始

这份文档面向第一次试用 NiumaClaw 的老板或小团队负责人，目标是在 5 分钟内完成注册、下载桌面端、连接本机 Agent、派第一条任务并看到工作日志。

## 1. 登录网页端

1. 打开 `https://niuma.wiki`。
2. 使用邮箱或手机号登录。
3. 首页出现公司工位、右侧账号中心和顶部操作按钮后，说明网页端已就绪。

## 2. 下载桌面端

1. 点击首页顶部的“下载客户端”。
2. Windows 点击“下载 Windows 桌面端”，macOS 点击“下载 macOS DMG”。
3. 下载后打开安装包，启动 `NiumaClaw Agent`。

完整安装步骤见 [macOS / Windows 安装教程](INSTALLATION_GUIDE.md)。

提示：macOS 未公证版本可能会被系统拦截，需要右键打开。正式商业发布前应完成 Developer ID 签名和 notarization。

## 3. 启动并确认连接

1. 桌面端打开后会显示服务器地址、节点号、工作区和首次启动向导。
2. 首次启动会检查服务器、工作区、Codex/Hermes/Claude Code 命令、Git、Node、Python。
3. 如果诊断失败，先按“下一步”提示修复；如果通过，客户端会进入“已连接，待命中”。
4. 保持桌面端窗口打开，回到网页端刷新“下载客户端”弹窗，看到“已发现在线客户端”即连接成功。

如果准备用 Codex 执行任务，请先完成 [Codex CLI 安装与登录说明](CODEX_CLI_SETUP.md)。

## 4. 绑定员工并派工

1. 点击一个空工位，填写员工姓名、职责和说明。
2. 选择本机 Runner 类型，例如 Codex。
3. 确认入职时，系统会绑定当前在线的桌面客户端节点。
4. 点击员工工位，输入第一条任务，例如“你好，请说明你能帮我做什么”。
5. 桌面端会收到任务并调用本机 Codex、Hermes 或 Claude Code 执行。

## 5. 查看结果和日志

1. 任务完成后，工位气泡会提示完成。
2. 点击“工作日志”查看老板指令、员工回复、运行状态和失败原因。
3. 需要复盘时，点击“复制日志”或“导出 Markdown”。
4. 智能体面板里可以查看客户端节点、最近心跳、最近运行和预算状态。

## 常见卡点

- 下载没反应：确认浏览器允许 `niuma.wiki` 下载文件，并重新点击下载按钮。
- 桌面端离线：保持 `NiumaClaw Agent` 窗口打开，刷新网页端客户端状态。
- `codex: command not found`：在终端先确认 `codex --version` 可用，再重启桌面端。
- 工作区不可写：把工作区改到用户目录下，例如 `~/NiumaClawWorkspace`。
- 节点不可用：在智能体面板里解绑旧节点，重新下载客户端并绑定。

更多处理方法见 [常见问题](FAQ.md)。

## 试用验收

完成下面 4 件事，就说明 MVP 闭环跑通：

- 网页端能看到一个在线客户端节点。
- 员工可以收到第一条任务。
- 桌面端能调用本机工具执行任务。
- 网页工作日志能展示最终回复，并支持复制或导出。
